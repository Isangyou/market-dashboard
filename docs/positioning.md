# 주간 포지셔닝 리포트 (weekly.html)

위클리 노트 [매크로] 섹션용. CTA 수급(모델) · 콜/풋옵션 포지셔닝 · 선물 포지션(COT)을 주 단위로 누적.

## 실행
```bash
cd ~/Documents/dash
.venv/bin/python -m positioning.run                        # 전체 → data/positioning/ 갱신, 결론 마크다운 출력
.venv/bin/python -m positioning.run --only cot             # 일부만 (나머지는 이번 주 기존 값 유지)
.venv/bin/python -m positioning.run --data-dir /tmp/pos    # 저장소 밖에 테스트
.venv/bin/python -m positioning.run --rebuild-conclusion   # 수집 없이 저장된 전 주차 결론만 재생성(규칙 바꾼 뒤)
gh workflow run positioning-weekly -R Isangyou/market-dashboard   # Actions 수동 실행
```
Actions: `.github/workflows/positioning.yml` — KST 화~토 07:10 (UTC 월~금 22:10). 푸시 후 pages.yml 호출.

## 주차·확정 규칙
- 실행 시각(KST) −14시간 = 미국 거래일. 그 주 금요일이 파일 키
- `확정` = CTA 기준일이 금요일 && COT 기준일이 그 주 화요일 && 실패 섹션 없음. 아니면 `진행 중`
- 휴일로 COT가 다음 주 월요일 공표 → 월요일 실행이 전주 파일에 COT 반영 후 확정
- 한 소스 실패 시: 이번 주 기존 값 → 없으면 전주 값을 쓰고 `stale`에 기록 (화면 상단 표시)

## 결론 (brief.py, 2026-10-18~ 데이터 성격 순 3블록)
수치만. 해석·전망 문장 없음. 주차 파일 `brief.blocks`에 저장 → 다음 주가 `prev.brief`와 비교. (10-05~10-17은 요약·변화 포인트·리스크 구조 — 재생성으로 전 주차 교체)
| 블록 | 성격 | 내용 |
|---|---|---|
| 1. 관측 포지션 (CFTC COT) | 관측 | ES 고정 + 주간 σ ≥ 1인 시장(최대 5개 합계). 시장마다 레버리지펀드·자산운용사(원자재는 운용역 MM): 순숏/롱 확대·축소, 주간 변화 k계약(σ), 순포지션. 나머지 ≥1σ 시장 수. 새 공표 없으면 "새 공표 없음" + 변화 없음 |
| 2. 관측 시장 상태 (옵션 시장) | 관측 | SPX ATM IV30 · 25Δ 스큐 · P/C(OI)·P/C(거래량 주평균) · 최대 콜·풋 OI 행사가(±15%, 전 만기, 현재가 대비 %) 각각 지난주 값·차이 + NDX·RUT IV30, VIX 옵션 P/C 한 줄 |
| 3. 추정 (모델 기반) | 추정 | 딜러 감마(방향·전환 여부, 규모는 보조) · zero-gamma(레벨, 지수가 선 위/아래) · CTA 포지션(방향·백분위·확대/축소) · CTA 전환가(가장 가까운 선·다음 선). 항목마다 `assume` 한 줄. 끝에 가장 가까운 기계적 임계값(risk) 한 줄 |

블록별 `unchanged`(화면 배지 "지난주와 변화 없음"): 1 = 새 공표 없음 또는 모든 σ < 1 · 2 = IV·스큐 < 1vp, P/C < 0.10, 최대 OI 행사가 동일 · 3 = 감마 부호 같고 |ΔGEX| < 5$bn, zero-gamma 거리 < 0.5%p, CTA < 5%p, 전환가 거리 < 0.5%p. 상단 "지난주 결론과 변화 없음" = 세 블록 모두 + 임계값 같음
기준 단위 `UNIT`: 전환가 거리 0.5%p · SPX 35일 GEX 5$bn · zero-gamma 거리 0.5%p · 25Δ 스큐 1vp · ATM IV 1%p · P/C(OI) 0.10 · COT 주간 변화 1σ · ES 포지션 5%p
근거 수치(report.py)도 같은 순서·태그: [관측] COT → [관측] 옵션 시장 → [추정] 딜러 감마 → [추정] CTA → [추정] 교차

## 쉽게 말하면 (easy.py, 2026-10-11~)
블록마다 `blocks[i].easy`(리스트). 관측 블록(1·2)은 관측값만으로 쓰고, 추정 블록(3)은 감마·전환가 해설을 각각 "모델상으로는 ~"으로 시작. COT 새 공표 없는 주는 COT 해설 생략.
종합(`overall`) = "관측: COT 상위 σ 2건 · SPX 옵션 IV30·스큐·P/C(둘 다 ≥ 기준 단위로 오르면 '옵션이 비싸지고 하락 대비 수요 증가') · 국채 레버리지펀드. 모델상으로는 딜러 감마 상태(부호 바뀐 주는 '자동 매수 흐름 소멸/복원' + 하방 안전판 겹수) · CTA 방향·백분위."
| 주제 | 내용 |
|---|---|
| 딜러 감마 | 순서 고정(2026-10-18~): (a) zero-gamma 선 위/아래 → 롱/숏 감마 상태(전주와 부호 다르면 '전환됐다') (b) 지수 1%당 딜러가 반대/같은 방향으로 N$bn(35일 GEX), 부호 같으면 전주 대비 배율(≥1.5배 두꺼워짐, ≤0.67배 얇아짐) (c) '쿠션'=지지선이 아니라 딜러 자동 매수 흐름이라는 정의 + 부호 전환 주는 원인 분해 ① 지수 이동 효과 = 이번 주 35일 프로파일(`gex_profile.near_usd_bn`)의 현재가 값 − 전주 현물가 값(복원됨) ② 만기 소멸 효과 = 전주 만기별 GEX 중 (전주 기준일, 이번 기준일]에 끝난 만기 합의 부호 반대(복원 안 됨; 전주 `gex_near_by_expiry` 없으면 `diag_gex_by_expiry` 상위 8개 → '최소치' 표기) ③ 나머지 = 신규·청산·35일 창 이동 (d) zero-gamma까지 % = 흐름이 바뀌는/복원되는 조건. 끝에 다음 주요 만기(월말물·월물 중 기준일 이후 가까운 것) |감마| 소멸 %, 만기가 기준일 이전이거나 0%·null이면 생략 |
| 옵션 시장(관측) | IV30 = 연 %·하루 약 %(÷√252), 지난주 대비 오름/내림/비슷(1%p) · 스큐 = 풋이 같은 거리 콜보다 N vp 비쌈, 하락 대비 수요 커짐/줄어듦(1vp) · P/C = 풋 계약이 콜의 N배, 풋 비중 늘/줄(0.10) + 주간 거래량 P/C · 최대 OI 행사가 위치·지난주와 같음/옮김 |
| COT | 주간 σ 상위 2개 시장: 주체·순숏/롱 확대·축소(숏커버)·계약 수·평소 주간 변동의 N배·시사(국채: 금리 상승 베팅 확대/축소)·순포지션 치우침(OI %, 3년 백분위). 나머지 ≥1σ 목록. 국채 레버리지펀드엔 베이시스 거래 주의 한 줄 |
| 전환가 | 가장 가까운 활성 전환가 = '지수 X% 하락 시 CTA 매도 시작선', 전주 같은 룩백 대비 0.5%p 이상 멀어짐=안전/가까워짐=위험, 1주 ∓1σ 포지션 변화, 다음 선, 하방 쿠션 겹수(딜러 롱 감마 구간 + CTA 롱 유지 구간) |
| 종합 | 감마 상태·쿠션 겹수 + CTA 방향/백분위/선까지 거리 + 국채 레버리지펀드 ≥1σ 변화(만기별 엇갈림 표기). 감마 부호가 바뀐 주는 맨 앞에 '딜러 자동 매수 흐름 소멸/복원(전주→이번 $bn, 소멸이면 zero-gamma 복원 조건)' + 하방 안전판 겹수(딜러 롱 감마·CTA 매도선) |

## 모델·가정 (요약 — 상세는 각 모듈 docstring)
- CTA: 룩백 20/60/125/250일 위험조정 모멘텀 tanh 평균 × 변동성 레버리지(3년 중앙 σ/60일 σ, 상한 1.5). ±100% = 정상 변동성 풀 포지션.
  전환가 = 다음 주말 기준 P_{t+5−L}. 시나리오 = 1주 ±1·2σ 로그 선형 경로 재계산
- 옵션 GEX: 딜러 콜 롱·풋 숏(naive) 가정, BS 감마(r=q=0) 재계산, $/지수 1%. VIX는 GEX 미계산
- COT: 헤드라인 = Leveraged Funds(금융)/Managed Money(원자재). 백분위·z 3년(156주), 주간 σ = 주간 변화/3년 주간 변화 표준편차
- 교차: 롱 크라우딩 = CTA 3년 ≥80p & COT ≥80p, 숏 = 둘 다 ≤20p, 괴리 = 부호 불일치 & |COT z|≥1

  - 규모 원인 = 전 만기 포함: 12/31 +23.6$bn, 9/30 +7.3$bn, 10/16 +4.4$bn … 공개 툴은 근월물 위주라 작게 나옴
  - 부호·zero-gamma는 공개치와 일치 방향: QuantWheel 9/25 gamma flip 7,721 vs 본 모델 7,687 (현물 7,743, 둘 다 양감마)
  - 반영: 당일 만기 제외(dte≥1), 행사가 ±25%·IV<150%·매도호가 존재만, 35일 이내 GEX 별도 표기, 벽은 순GEX 기준
  - 다음 만기(`next_opex`, `next_opex_kind`): 2026-10-18 수정 — 이전엔 기준일(금요일)이 셋째 금요일이면 그날을 골라(`tf >= today`) 이미 제외된 당일 만기 비중 0%가 나왔음. 이제 체인의 기준일 이후 만기 중 월말물(그 달 마지막 만기)·월물(셋째 금요일) 가까운 것
  - zero-gamma(`zero_gamma`)는 전 만기 프로파일 기준, 해설의 감마 부호는 35일 GEX 기준이라 둘이 약간 어긋날 수 있음(10-16 주: 전 만기 7,744 vs 35일 7,775)
